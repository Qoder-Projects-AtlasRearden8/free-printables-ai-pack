### Outputs

- `site/index.html` — gallery with all 12 printables, a 6/6 balance summary, accessible filters, and `?filter=ai` / `?filter=life` deep links.
- `site/print/*.html` — print-ready HTML for each guide, plus `complete-pack.html`.
- `site/downloads/01-…12-*.pdf` — twelve individual PDFs.
- `site/downloads/asdale-practical-life-pack-complete.pdf` — 168-page combined PDF.
- `site/downloads/asdale-practical-life-pack.zip` — the twelve current PDFs.
- `.build-manifest.json` — generated source of truth for slugs, titles, groups, files, and page counts.

The sources are the twelve Markdown files in `docs/`. The gallery, print HTML, PDFs, ZIP, and manifest are generated by `tools/build.mjs`.

### Design and content choices

- **ADHD-friendly layout:** short entry points, no required order, no streaks, checkboxes, generous writing lines, explicit stop points, and low-effort alternatives.
- **50/50 balance:** six AI guides and six life-admin guides. The gallery says so in the stats, filters, about section, and download card.
- **Local-first:** bundled fonts, no accounts, cookies, analytics, remote scripts, or backend. The gallery makes no network requests.
- **Privacy-aware prompts:** the AI guides and money/health pages explicitly tell readers not to paste names, account numbers, health records, or other private details into consumer AI tools.
- **Clear limits:** education only. Medical, legal, tax, benefits, and financial content points to qualified humans and official sources; emergency instructions point to local services.
- **Print-first:** fixed US Letter pages, restrained ink coverage, visible page numbers, and a footer that repeats the guide title.

## How to run it

### Use the pack

Open `site/index.html` directly in a browser, or serve the folder:

```bash
npm run serve
# then open http://localhost:8080
```

No install step and no npm dependencies are needed. Download a guide, the complete PDF, or the ZIP from the gallery. For printing, use **100% scale** on US Letter; on A4 choose **fit to page** and enable background graphics for the intended look.

### Rebuild it

Requirements: Node.js 18+, Google Chrome or Chromium for PDFs, `pdfinfo` from Poppler for page checks, and Python 3 for ZIP creation.

```bash
npm run build
```

The build regenerates all HTML, PDFs, the combined PDF, the ZIP, the gallery, and `.build-manifest.json`. Without Chrome, the build still writes the HTML and gallery but skips PDF rendering.

### Verify it

```bash
npm test          # full suite
npm run status    # summary only
```

## Known gaps

- **Uneven page counts across guides.** The AI guides run 7–15 pages and the life-admin guides 16–19. The split is 50/50 by guide and by gallery prominence, not by identical page count. The AI titles are more reference-style; the life-admin titles are workbook-style.
- **Fixed pagination is manual.** Content is placed with `<!-- page -->` markers and authored to fit; there is no automatic pagination. Adding a paragraph can overflow a page, so the workflow is: edit, `npm run build`, `npm test`. The verifier names the exact page if it clips.
- **Overflow is measured in Chrome only.** The check uses headless Chrome at 1440 × 1000, which matches the PDF renderer. Other browser engines, unusual font fallbacks, or later CSS changes could shift the layout by a few pixels.
- **Tooling dependencies.** Rebuilding PDFs needs Chrome; page-size verification needs `pdfinfo`; ZIP creation and inspection need Python 3. The static gallery and HTML still work without any of them.
- **Static PDFs.** There are no fillable form fields, embedded JavaScript, or interactive checkboxes. The pages are designed to print and be completed by hand.
- **Filtering needs JavaScript.** Without JavaScript, all twelve cards stay visible and usable; the filter buttons simply do nothing. The content is never hidden by default.
- **US Letter first.** A4 is supported by the printer’s “fit to page” setting, not by a separate A4-native layout. There is no large-print edition or translation yet.
- **Not professional advice.** The pack is educational. It is not medical, nursing, legal, tax, benefits, or financial advice, and it is not a clinical tool for ADHD or any other condition.
- **No remote publishing.** The project is complete locally and has not been pushed to a remote, deployed, or published. The user asked for that boundary and it has been respected.
